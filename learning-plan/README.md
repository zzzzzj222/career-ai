## 每晚如何跟进

北京时间 **22:30** 在本聊天检查最新反馈和本地项目变化：核对完成证据，指出最重要的不足，安排一项针对性补练，并调整次日目标。你可以直接发“今天做了什么、文件在哪里、运行结果、卡在哪里、花了多久”。

按用户最新要求跟进。基础接口运行结果和错误请求免验收；ORM重点看概念理解、独立修改和项目产物。遇到前置能力不足，安排针对性补练并顺延。

自动检查本地文件时，电脑需开机且应用保持运行。没有新证据时保留当前状态并补问，不把沉默记为失败。
