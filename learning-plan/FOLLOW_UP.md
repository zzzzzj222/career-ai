# 每日跟进与调整规则

目标岗位：AI 解决方案 / AI 实施工程师。每天投入 3–4 小时，北京时间 22:30 在本聊天跟进。

2026-10-05用户最新调整：已推进到ORM；基础接口运行结果和错误请求免验收，P01按用户确认记为已完成，不再索取其HTTP记录、错误请求或基线报告。当前P02为ORM进行中，围绕模型、Session、CRUD、事务与独立修改跟进。用户明确免验收的项目优先于下文通用规则，并注明依据，不宣称已独立验证。

## 记录如何维护

- `plan.json` 保存 P01–P70 的任务、资料、计划日期和当前状态。P 编号固定，不对应仓库原有 day 目录编号。
- `DAILY_PLAN.md` 是可直接阅读的完整清单，Excel 是便于筛选和勾选的版本。读取plan.json中的workbook_path获取当前表格路径；现在使用ORM更新版，不能再从旧表覆盖进度。两者由计划数据生成。
- `PROGRESS.md` 保存每次验收证据、未解决问题与调整原因。以这份验收记录确认是否真正完成。
- 用户在 Excel 的状态、完成日期、备注、实际小时和证据栏填写的是自报进度。重新生成表格前，必须先读取并合并这些改动；不能覆盖用户未合并的填写。若与聊天或验收记录冲突，保留双方原值，询问具体差异后再处理。
- 每次修改保留原计划日期为 `baseline_date`，用 `planned_date` 表示调整后的日期。新增补课使用 S01、S02 等独立编号并记录关联 P 编号，不偷偷删除未完成任务或重编号。

## 每晚的跟进顺序

1. 查看本聊天最近的学习反馈、`plan.json`、`PROGRESS.md`、Excel 手填内容，以及项目自上次检查后的相关文件和提交。未提交的学习内容也算证据。跳过环境文件、凭据和无关文件。
2. 明确区分：代码存在、实际运行通过、能够独立解释并做一次小改动。只有当日验收要求的证据齐全，才标记“已完成”；代码量、提交次数、读过教程、助手代写文件均不等于学会。
3. 对照当日验收逐条判定“通过 / 待补证据 / 未通过”，引用具体路径、请求返回或测试记录。缺少学习耗时、自主理解等信息时直接问用户，不从 Git 推测。
4. 每次只指出最重要的 1–3 个不足；为每个不足给出原因、一项 30–60 分钟补练、对应教程小节和重新验收方式。
5. 给出明天的一个主要目标、分时任务、学习链接、提交物和验收标准。默认总计 3–4 小时，保留 30 分钟排错余量。
6. 更新已证实的状态和进度日志。有实际调整时，同步未来 7 个学习日与清单，记录调整前后及原因。远期路线只在每周复盘或出现重大依赖问题时调整。

用户明确要求每天跟进，所以每天可以发一条简短检查结果。没有新证据时，只说尚未收到哪些证据和下一步要提交什么；不要重复整份计划，也不要默认用户没有学习。

## 调整触发条件

| 观察到的情况 | 调整办法 |
| --- | --- |
| 提前通过，而且能脱离教程解释并修改 | 免做已验收的重复练习，将节省的时间用于失败案例或提前进入下一项；保留任务和通过证据 |
| 当日未完成，但下一项不依赖它 | 保留未完项，利用本周复盘日补齐；不把两天任务叠成超时的一天 |
| 未掌握下一项依赖的能力 | 明天先做 30–60 分钟针对性补练并复验；未通过则暂停依赖项，顺延日期 |
| 同一问题连续 2 次未通过 | 缩小到一个最小例子，补一个明确概念；先让用户自己解释，再重新写或调试 |
| 连续 2 天耗时超过 4 小时，或一周完成少于 5 个计划日 | 将下一周任务量下调约 25%，延长日历；保留最终交付要求 |
| 一周全部验收通过且能独立完成 | 缩减已掌握内容，只选一个更贴岗位的扩展；不堆更多框架 |
| 评测达不到本项目预定门槛 | 先分类失败：数据、检索、生成、权限、工具、界面。优先修最大一类，用开发/回归集复验；首次独立成绩保留，一旦参考独立题修复，该集只能用于回归，新配置的独立验证需要另行提前封存新题 |
| 环境安装或下载排错超过 60 分钟 | 插入环境补课并顺延，保留已有环境；Embedding 使用受依赖支持的独立 Python 环境，Docker 至少提前3个学习日检查可用性。每天 3–4 小时已包含排错，不另行加时 |
| 目标岗位的真实 JD 与路线明显不符 | 以 10–20 份真实 JD 的共同要求为依据调整；向用户说明舍弃什么、补什么及时间影响 |
| 没有学习反馈或本地变化 | 保留状态，询问是否离线学习或需要休息；不补造完成记录，也不自动加码 |

SQL 基础已掌握，不重新安排 SQL 基础、复习或额外水平考试。后期 NL2SQL 是模型与只读数据库集成任务。

## 每周关口

每 7 个学习日复盘一次：本周产物能否复现、验收证据是否完整、能否独立说明关键决策、下周前置能力是否齐备。未达关口时，先用复盘日修复，再调整后续日期。周数表示学习批次，不表示必须在自然周末完成。
